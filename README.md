# CampusOne - Smart University Digital Campus

Team: **Bit Heads** | Category: Technical | Challenge: Smart University Digital Campus

CampusOne is a mobile-friendly web app that puts everyday campus services in one place.

## Features
- **Attendance tracker** with a 75% calculator (classes you can skip or must attend)
- **Room and lab booking** by time slot; taken slots are blocked
- **Helpdesk** to raise complaints and track status (Reported, In progress, Resolved)
- **Notices** with filters: exam, event, fees, placement
- **Canteen pre-order** with a pickup token
- **Campus shuttle tracker** (simulated in the demo)
- **Digital ID** and a home dashboard
- Light and dark theme, works on phone and laptop

## Run locally
No install needed. Open `index.html` in any browser.

## Tech stack
- Front end: HTML, CSS, vanilla JavaScript (single file)
- Data in the prototype: sample data, saved in browser localStorage

## Roadmap
1. Prototype (done)
2. Backend API (Node.js or Python), database, college-email login
3. Admin panel for staff
4. Pilot in one department or hostel
5. ERP integration and push notifications

## Notes
This is a prototype. Attendance, timetable and notices use sample data in place of real college records.
